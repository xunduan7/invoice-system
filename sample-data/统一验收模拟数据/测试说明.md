# 九类验收测试数据

这套数据参照横向电子普通发票的字段与表格布局生成，所有身份、号码均为虚构，页面标明“非真实发票”。共 **9 张不同的 PDF＋1 个 ZIP**；ZIP 只是复用其中两张 PDF，并未增加新的发票数据。考核的统一测试不提供支付凭证；`支付凭证/` 中另放了本地演示用的 5 组模拟订单截图与支付记录。

| 验收类型 | 使用文件 | 要观察的结果 |
|---|---|---|
| 1. 普通材料发票 | `01_普通材料_320.pdf` | 开发板单价 320 元；字段完整、品类允许、无需凭证。 |
| 2. 低值品发票 | `02_低值品_650.pdf` | 电烙铁单价 650 元；提示补订单截图和支付记录。 |
| 3. 资产发票 | `03_资产_1200.pdf` | 电机单价 1200 元；虽是允许品类，仍不能走材料费。 |
| 4. 同商家周累计 | `04_周累计_A_400.pdf`、`05_周累计_B_600.pdf` | 销售方税号相同、开票日期不同；在同一自然周运行预审后累计恰好 1000 元。 |
| 5. 超过 1000 元 | `06_周累计_C_放弃_100.pdf` | 在 04、05 已资质审核通过后，当前加入变成 1100 元；页面应提供补齐相关凭证和放弃当前发票的路径。 |
| 6. 超过 3000 元 | `07_累计超3000_前序2700.pdf`、`08_累计超3000_当前400.pdf` | 07 必须先完成凭证核验和资质审核；随后 08 加入使有效累计达到 3100 元，应直接不通过。 |
| 7. 品类问题 | `09_品类三态_混合商品.pdf` | 同一张含开发板、SD 卡、鼠标，分别检查“可以、存疑、不可以”；整张不能直接通过。 |
| 8. 重复发票 | 再次上传 `01_普通材料_320.pdf` | 同一个 PDF 被重复上传，应提示重复；无需另造一张。 |
| 9. ZIP 批处理 | `验收_ZIP批处理.zip` | 内含 01、02 的副本，其中 02 在子目录；还含 TXT 和故意损坏的 PDF。两个正常 PDF 应独立建档，单文件失败不拖垮整批。 |

## 使用顺序

建议从**空数据库**开始，先上传 ZIP，借此建档 01、02；再单独上传 03～09。这样随后重传 01 就能验证重复提示。不要先上传 01、02 再上传 ZIP，否则 ZIP 中这两张会按重复文件跳过，无法观察两个新建档结果。

周累计场景需在同一个自然周操作：先预审 04 并将资质审核标记为通过，再预审 05 并标记通过，然后预审 06。04、05 的开票日期不同，考核要求的累计口径是**提交审核时间**，不是开票日期。

3000 元场景有前置条件：07 自身已超过 1000 元，必须先有匹配的模拟支付凭证并经管理员核验、资质审核通过，它才会计入有效累计。可使用 `支付凭证/07_2700元/` 的两张图片；未完成这一步时，08 不会触发 3100 元拒绝，这是业务规则的正常结果。

## 本地演示用支付凭证

`支付凭证/` 按发票编号分组，每组恰好一张“订单截图”和一张“支付记录”，均为 PNG；两张图的发票号码、订单号、销售方和金额一致。管理员需要把两张图上传到**对应发票**的“支付凭证”页，并点击该凭证组的“核验通过”。凭证仅用于演示，不能代表真实交易。

| 发票 | 凭证目录 | 什么时候需要 |
|---|---|---|
| 02，650 元 | `支付凭证/02_650元/` | 低值品必须补。核验后重新运行 02 的自动预审。 |
| 04，400 元 | `支付凭证/04_400元/` | 若保留 06，需补齐同周参与累计的历史发票。 |
| 05，600 元 | `支付凭证/05_600元/` | 若保留 06，同上。 |
| 06，100 元 | `支付凭证/06_100元/` | 若选择补齐凭证保留 06；若选择放弃 06，则不需要上传。 |
| 07，2700 元 | `支付凭证/07_2700元/` | 07 本身累计超过 1000 元；核验并使 07 资质审核通过后，才能测试 08 超过 3000 元。 |

测试“保留 06”时：先让 04、05 通过资质审核；预审 06 后，分别给 **04、05、06** 上传并核验各自凭证，再重新运行 06 的自动预审。后端已允许给历史资质审核通过的 04、05 补验凭证；更新代码后要重新启动后端。08 超过 3000 元直接不通过，不需要凭证。

九类是验收场景数，不等于每类只用一张 PDF。周累计和 3000 元判断必须有前序发票；重复检测可复用同一文件；ZIP 可复用现有 PDF。扫描件 OCR 不是截图表格中的独立验收类型，需要另外测试时可用项目原有的无文字层 PDF。

四分钟视频只需展示 ZIP 上传、01 正常通过、02 提示凭证、03 资产拦截、09 品类三态。其余案例留作答辩或自己检查，不必全部录入视频。AI 结构化与 OCR 结果仍应人工核对。
